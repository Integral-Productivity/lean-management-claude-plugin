# A3 files of record

This folder holds the A3s whose topic is this repository. Each A3 is one file named by its A3 ID, for example `A3-2026-01-15-late-invoices.md`.

The format is `a3/v1`. See the [`a3-reference`](../../skills/a3-reference/SKILL.md) skill and [ADR-0003](../adr/0003-an-a3-of-record-lives-in-git-as-markdown-with-an-id-for-each-component.md). `node scripts/check-a3.mjs` checks every file here.
